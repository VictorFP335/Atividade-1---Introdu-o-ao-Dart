 Atividade prática em Dart – Manipulação de dados e cálculo de métricas

Nesta atividade da faculdade desenvolvi um programa em Dart contendo quatro exercícios focados em manipulação de listas, transformação de dados e cálculos matemáticos, aplicando conceitos importantes para programação e análise de dados.

No primeiro exercício, trabalhei com uma lista de preços de fechamento, realizando operações como soma total, média aritmética, ordenação dos valores e cálculo de amplitude entre o maior e o menor valor. Utilizei métodos como reduce(), sort() e propriedades de listas para obter os resultados.

No segundo exercício, implementei um pipeline de limpeza e transformação de dados. A lista original continha valores com espaços, textos inválidos e dados nulos, então utilizei map(), where() e trim() para limpar as informações e convertê-las para números do tipo double.

No terceiro exercício, fiz a normalização dos dados usando a fórmula Min-Max, que transforma valores para um intervalo entre 0 e 1. Esse tipo de técnica é muito utilizado em ciência de dados e machine learning, pois facilita o processamento e comparação de valores.

No quarto exercício, implementei uma função para calcular o MSE (Mean Squared Error), que mede o erro entre valores reais e valores previstos. O código inclui validação de entrada, tratamento de erro e uso da biblioteca dart:math para calcular potências, mostrando a importância de escrever funções reutilizáveis e seguras.

Durante a atividade também utilizei IA como apoio para organização do código e revisão da lógica, mantendo o foco no entendimento dos conceitos e na implementação prática.

 Linguagem: Dart
 Tema: Manipulação de dados, listas, normalização e métricas de erro
